## The patch note

> v3.2.0: fixed a bug where the brain replayed embarrassing moments from 2014 every time the user tried to fall asleep.

## Where the joke is

It treats the brain like shipped software with a known, unpatched bug: the
cringe-replay feature that only ever triggers at bedtime, never at a useful
moment. The dry release-note wording ("fixed a bug where...") makes an
all-too-human experience sound like a routine hotfix, which is exactly why
it lands.

## How to run

```bash
python3 main.py
```

This writes the single line above to `/output/entry.txt` (UTF-8, one line,
no trailing newline). The program also asserts the line is 1–160 characters
long and contains no newline. Standard library only, no network, no randomness —
running it twice produces byte-identical output.
